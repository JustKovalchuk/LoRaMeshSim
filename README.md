# LoRa Star vs Mesh Network Simulator (SX1276)

Цей програмний комплекс призначений для моделювання та порівняльного аналізу ефективності роботи бездротових мереж стандарту **LoRa** у двох топологіях: **"Зірка" (Star)**, що характерна для LoRaWAN, та **"Сітка" (Mesh)**.

Програма дозволяє візуалізувати вплив міських перешкод (будівель, стін) на зону покриття, енергоспоживання та надійність доставки даних (PDR).



## 🚀 Основні можливості

* **Моделювання перешкод:** Генерація випадкових об'єктів (будинки, стіни), що динамічно блокують сигнал між вузлами.
* **Розрахунок ToA (Time on Air):** Реалістичний розрахунок часу передачі пакета на основі параметрів фізичного рівня LoRa ($SF$, $BW$, $CR$).
* **Енергоаналіз:** Детальний розрахунок споживання енергії (в Джоулях або mAh) на базі специфікацій трансивера **Semtech SX1276**.
* **Порівняння метрик:** 

    * **PDR (Packet Delivery Ratio):** Відсоток успішно доставлених пакетів до шлюзу.
    * **Coverage:** Кількість покритих вузлів у кожній топології.
    * **Relay Load:** Визначення критичних вузлів-ретрансляторів з найбільшим навантаженням.
* **Пакетне тестування:** Запуск серії зі 100 симуляцій для отримання статистично значущих результатів.

## 📖 Математична модель

### Time on Air (ToA)
Час передачі пакета розраховується як сума:
$$T_{packet} = T_{preamble} + T_{payload}$$
Де кількість символів залежить від вибраного Spreading Factor ($SF$) та Bandwidth ($BW$).

### Енергоспоживання
Енергія для кожного вузла розраховується на основі напруги живлення ($V_{supply}$) та струму ($I$) у різних режимах:
$$E = V_{supply} \times I_{mode} \times T_{packet}$$
Для Mesh-вузлів, що працюють ретрансляторами, враховується енергія як на прийом ($I_{RX}$), так і на пересилання ($I_{TX}$) даних.



## ⚙️ Використання

1.  **Налаштування:** Встановіть кількість вузлів, радіус зв'язку та кількість перешкод у бічній панелі.
2.  **Генерація:** Створіть карту перешкод та розмістіть вузли кнопками "Генерувати".
3.  **Gateway:** Клікніть у будь-якій точці карти, щоб перемістити Шлюз (зірочка на мапі).
4.  **Аналіз:**

    * Натисніть **"Запустити симуляцію"** для візуалізації поточних шляхів.
    * Натисніть **"Запустити серію"** для отримання середніх показників ефективності.

## 📊 Інтерпретація результатів

* 🔵 **Сині вузли:** Вузли, що мають прямий зв'язок зі шлюзом (Star).
* 🟢 **Зелені вузли:** Вузли, доступні тільки через Mesh-маршрутизацію.
* 🔴 **Червоні вузли:** Вузли поза зоною досяжності.
* 📏 **Розмір вузла:** Відображає відносне енергоспоживання (великі вузли — кандидати на швидке виснаження батареї).
